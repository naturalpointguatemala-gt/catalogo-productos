CATÁLOGO PRODUCTOS - GITHUB PAGES

1. Crea un repositorio PUBLICO nuevo en GitHub, por ejemplo catalogo-productos.
2. No agregues README ni licencia al crearlo.
3. Instala Git for Windows si no lo tienes.
4. Abre CMD dentro de esta carpeta y ejecuta:
   git init
   git branch -M main
   git config user.name "Natural Point Catalogos"
   git config user.email "TU_CORREO"
   git remote add origin URL_HTTPS_DEL_REPOSITORIO
5. Ejecuta iniciar_catalogo.bat y haz un cambio en la carpeta de OneDrive.
6. Tras 60 segundos sin cambios, generará el catálogo y hará git add/commit/push.
7. En GitHub activa Pages:
   Settings > Pages > Deploy from a branch > main > /(root) > Save
8. GitHub mostrará la URL pública del catálogo.

El repositorio será público: no incluyas archivos privados.
